# Prospective 24-Target Data

`Prospective_24_Target_Design_Prespecified.csv` and `Prospective_24_Target_Summary.csv` belong to the **original conservative prospective validation implementation**. In particular, `policy_tuning_runs` in the summary records the original 0 / <=116 / 1250 schedule and sums to 6,185 runs. These values are retained because they underpin the original confirmatory 21/24 analysis.

The manuscript's **recommended operational staged policy** is not encoded by overwriting these historical columns. Its 50 / 137 / 490 maximum budgets and observed 24-target total of 3,767 tuning runs are distributed separately under `../../recommended_operational_policy/` and `../../protocol/Recommended_Risk_Guided_Operational_Policy_v1.0.json`.
